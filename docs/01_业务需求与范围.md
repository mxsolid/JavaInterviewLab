# 01 业务需求与范围

## 1. 产品定位

Java Interview Lab 是面向 Java 后端社招的本地学习系统，核心用户是已有开发经验、但基础体系、源码理解、复杂场景设计不够完整的开发者。

产品不是“题目收藏夹”，而是形成：

**知识讲解 → 面试回答 → 高频追问 → 练习 → 错题 → 复习 → 场景训练**

的闭环。

## 2. V0.1 业务目标：能系统学题

用户可以：
- 浏览知识树；
- 按分类、专题、星级、难度、高频度筛题；
- 查看题目不同深度答案；
- 查看“为什么这样设计”；
- 查看常见错误和得分点；
- 查看追问题；
- 点击英文术语喇叭发音；
- 自定义新增、编辑、停用题目；
- 导入初始化题库。

### 典型页面
- 首页
- 知识地图 / 分类
- 题库列表
- 题目详情
- 题库管理

## 3. V0.2 业务目标：能长期学，不丢进度

用户可以：
- 选择 10 / 15 / 30 天路线；
- 标记预习、学习、练习、掌握；
- 答题后自评；
- 自动进入错题本；
- 收藏；
- 写笔记并自动保存；
- 看到今日应复习内容；
- 看到总进度、五星掌握率、连续学习等指标。

## 4. V0.3 业务目标：场景驱动

场景不是一道题，而是一组现实变体。

示例：`支付重复处理 ★★★★★`

- Case A 用户疯狂点击支付按钮
- Case B 支付平台重复回调
- Case C 网关超时客户端自动重试
- Case D MQ 重复投递支付成功消息
- Case E 多实例并发处理同一通知

每个 Case 展示：
- 现象；
- 根因；
- 风险；
- 错误做法；
- 可选方案；
- 方案优缺点；
- 推荐组合；
- 为什么这样设计；
- 面试追问；
- 关联知识。

## 5. 非功能需求

### 数据可靠性
- 题库、进度、答题记录、错题、笔记全部 PostgreSQL 持久化。
- 答题历史不可覆盖。
- 笔记使用乐观锁。
- 提供后续备份 / 导出扩展点。

### 可维护性
- 所有可扩展类型使用枚举或表驱动。
- 不把内容逻辑写死在前端。
- 题库内容与程序版本解耦。
- Seed 有版本号和来源。

### 易学
- 重要内容必须解释“为什么”。
- 代码示例必须有简体中文注释。
- 不默认学习者知道所有英文缩写。
- 技术术语可以点击发音。
