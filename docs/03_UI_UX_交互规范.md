# 03 UI / UX 与交互规范

## 1. 视觉方向

采用已选中的“白色教育产品”方向：

- 页面背景：近白
- 主色：蓝
- 辅助：紫 / 青绿
- 圆角：统一 Token
- 阴影：弱、克制
- 卡片：信息分组清晰
- 星级：始终使用统一组件
- 不做传统厚重后台管理风格

## 2. 布局

桌面优先，兼容 1280～1920 宽度。

左侧主菜单：
1. 首页
2. 开始学习
3. 题库
4. 场景训练
5. 复习中心
6. 管理 / 设置

源码、动画、发音不做一级菜单。

## 3. 题目详情交互

建议固定结构：

```text
题目标题 ★★★★★       收藏
标签 / 难度 / 高频

[一句话理解]
[通俗讲解]
[为什么这样设计]

Tab:
30秒回答 | 标准回答 | 深入回答

高频追问
典型场景
易错点
得分点
相关知识
笔记
```

重要原则：
- 答案默认可折叠；
- 练习模式先隐藏答案；
- 术语旁统一喇叭图标；
- 代码统一高亮和中文注释。

## 4. 场景页

左：Case 列表。
中：当前 Case 的问题、根因、方案。
右：方案对比 / 关联知识。

支付重复处理示例必须保留 Case A～E 的模式。

## 5. 统一交互组件

必须复用：
- StarRating
- MasterySelector
- QuestionStatus
- AnswerTabs
- EnglishTermSpeaker
- MarkdownRenderer
- NoteEditor
- SolutionMatrix
- RelationChips

## 6. 动画规范

前三版只做 UI 微动画：
- 进入 150～220ms
- hover 120～180ms
- 展开 180～240ms

教学动画 V0.5 再做统一 AnimationEngine。
禁止前三版把大量 Token 消耗在 B+ 树动画上。

## 7. 无障碍和易读性
- 正文不得过小；
- 代码区允许横向滚动；
- 关键状态不能只靠颜色区分；
- 喇叭按钮有 tooltip；
- 所有按钮有明确文字或 aria-label。
