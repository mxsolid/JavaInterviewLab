## V0.1：题库

建议严格顺序：
A05 分类专题 → A06 题目答案追问 → A07 管理页 → A08 学习页 → A09 搜索 → A10 发音 → A11 Seed → A12 验收。

验收关键：
- 用户可以真正增加一道题；
- 可以编辑不同层级答案；
- 可以添加追问；
- 可以搜索；
- 可以查看详细解释；
- 重启后内容仍在。

## V0.2：学习闭环

严格顺序：
B01 路线 → B02 答题历史 → B03 进度 → B04 错题收藏 → B05 笔记 → B06 复习 → B07 仪表盘 → B08 可靠性测试。

验收关键：
- 连续答题、重启应用后进度不丢；
- 历史答题不会被新答题覆盖；
- 笔记保存失败有提示且内容不消失；
- 今日复习可正确生成；
- 首页指标来自数据库，不是假数据。

## V0.3：场景训练

严格顺序：
C01 模型 → C02 CRUD → C03 Case 页面 → C04 矩阵 → C05 关联 → C06 追问树 → C07 支付示例 → C08 其他场景 → C09 验收。

验收关键：
- 一个场景能有多个 Case；
- 一个 Case 能比较多个 Solution；
- 同一方案可以复用到不同 Case；
- 支付重复处理 Case A～E 可完整展示；
- 推荐方案不是写死在 React 组件。

## Agent Token 控制

### 推荐做法
- 每个任务独立新 Agent 会话；
- 提示词只附相关文档；
- 让 Agent 先检索目标代码，不读无关目录；
- 一次只解决一个验收目标；
- Seed 内容按 10～30 题一批生成并 Review。

### 最浪费 Token 的做法
- 每次让 Agent 重读整个项目；
- “顺便重构”；
- 一次生成几百道高质量题；
- 同时开发前端、后端、动画、AI；
- 没有测试导致反复修。
