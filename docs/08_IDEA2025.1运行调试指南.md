# 08 IDEA 2025.1 打开、运行、调试指南

## 1. 打开项目

IDEA 2025.1：
1. File → Open
2. 选择：
   `D:\Develop\project\Ai\JavaInterviewLab`
3. Trust Project
4. 后端 Maven 自动导入。

## 2. 配置 JDK

File → Project Structure → SDK：
- Add JDK
- 选择 `D:\Develop\Java\jdk-21`

Project SDK 设为 21。

## 3. Maven

Settings → Build Tools → Maven：
- Maven home path 指向 `D:\Develop\maven` 下选定 Maven 版本；
- JDK for importer = Project JDK 21。

如果有多个 Maven，运行：
`scripts\01_check-env.ps1`
查看可用版本。

## 4. 数据库

在 IDEA Database 工具窗口新增 PostgreSQL 数据源。

本地开发默认建议：
- Host: localhost
- Port: 5432
- Database: java_interview_lab
- 用户名 / 密码放 `.env.local` 或 IDEA Environment Variables

禁止提交真实密码。

## 5. 后端运行

找到主类：
`JavaInterviewLabApplication`

Run 正常运行。

Debug：
点击 Debug。

local profile 必须输出：
- 应用启动信息；
- 当前 profile；
- 数据库连接结果；
- Flyway migration；
- HTTP 请求关键日志。

禁止输出数据库密码。

## 6. 前端运行

IDEA Terminal 使用 PowerShell 7：

`D:\Tools\PowerShell\7\pwsh.exe`

执行：
```powershell
chcp 65001
cd frontend
npm install
npm run dev
```

如果 Node 未安装，由 Agent 记录为环境依赖，不擅自修改系统 PATH。

## 7. 后端 Debug 日志

开发环境推荐：
- root: INFO
- `com.javainterviewlab`: DEBUG
- SQL：调试阶段按需 DEBUG，默认不要刷屏

关键业务日志示例：
- 创建题目；
- 修改题目；
- 提交练习；
- 更新掌握度；
- 保存笔记；
- 场景内容导入。

日志必须包含业务 ID，不记录完整答案正文。
