# 09 日志、注释与编码规范

## 1. 中文注释

正确：

```java
// 先写入答题历史，再更新当前学习快照。
// 两者必须在同一事务中，避免出现“进度更新了但答题历史丢失”的不一致状态。
```

不推荐：

```java
// 更新进度
progress.update();
```

## 2. Javadoc

公共核心 Service 可写中文 Javadoc，重点说明：
- 业务职责；
- 事务边界；
- 关键参数；
- 可能抛出的业务异常。

不要给每个 getter/setter 写废话注释。

## 3. 日志

使用参数化：

```java
log.info("题目创建成功, questionId={}, topicId={}", questionId, topicId);
```

不要：

```java
log.info("题目创建成功：" + questionId);
```

## 4. 错误日志

异常只在统一边界记录一次，避免 Controller、Service 重复打印同一个堆栈。

## 5. TraceId

后端统一请求过滤器生成 / 透传 traceId：
- 响应体返回；
- 日志 MDC 包含；
- 方便定位前后端问题。

## 6. UTF-8

所有：
- `.java`
- `.xml`
- `.yml`
- `.json`
- `.md`
- `.sql`
- `.tsx`
- `.ts`
- `.ps1`

均使用 UTF-8。

`.editorconfig` 应明确：
`charset = utf-8`
