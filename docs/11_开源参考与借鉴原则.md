# 11 开源参考与借鉴原则

## 推荐研究方向

### JavaGuide
用途：
- Java 面试知识范围
- 高频分类方式
- 项目 / 系统设计题方向

### doocs/advanced-java
用途：
- 高并发
- 分布式
- 高可用
- 中间件场景

### macrozheng/mall 与 mall-swarm
用途：
- 商品
- 订单
- 促销
- 库存
- 商城模块边界
- 微服务业务拆分

### Hello Algo
用途：
- “图解 + 逐步操作”的教学思路

### Algorithm Visualizer
用途：
- 动画播放、步骤化演示结构

### Snailclimb/interview-guide
用途：
- 后续 AI 模拟面试、PostgreSQL / Redis / AI 架构研究

## 原则

1. 借鉴信息架构、业务思路和公开技术方案。
2. 不大段复制题解和文章。
3. 外部来源记录 URL / License / 日期。
4. 源码引用必须遵守原项目许可证。
5. 系统自己的“为什么这样设计”的讲解应重新组织成适合基础偏弱学习者的原创解释。
