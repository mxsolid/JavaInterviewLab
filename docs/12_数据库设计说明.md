# 12 数据库设计说明

V1～V3 已执行，后续表结构只能通过 V4 及之后的 Flyway migration 修改。

| 表 | 用途与约束 |
|---|---|
| `category` | 知识分类。`id` 主键，`code` 唯一，`status` 用于停用。 |
| `topic` | 分类下的专题。`category_id` 外键，`code` 唯一。 |
| `question` | 题目主表。`topic_id` 外键，`external_key` 供 Seed 幂等，`version` 供乐观锁。 |
| `question_answer` | 分层答案。`question_id` 外键，`question_id + answer_type` 唯一。 |
| `question_follow_up` | 题目追问。`question_id` 外键。 |
| `tag` / `question_tag` | 标签及题目多对多关系；关系表双外键、组合主键。 |
| `seed_import` | 已导入种子包与版本记录。`seed_pack` 为主键。 |

题目不物理删除，使用 `status` 保留内容可追溯性。`version` 条件更新阻止旧编辑页覆盖新内容。题量增长后应为 `question(topic_id, status, updated_at)` 与筛选组合索引评估真实查询计划后再建索引。
