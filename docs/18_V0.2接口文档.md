# 18 V0.2 接口文档

本文件记录 B01 已提供的学习路线接口。统一响应沿用 `ApiResponse`。

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/study/plans` | 返回 10 天、15 天、30 天预设路线摘要。 |
| GET | `/api/study/plans/{planId}` | 返回路线的每日计划和关联内容。 |
| POST | `/api/study/plans/{planId}/activate` | 选择路线并开始一轮新的自然时间进度。 |
| GET | `/api/study/current-plan` | 返回当前路线；未选择时 `data` 为 `null`。 |
| GET | `/api/study/today` | 返回当前 Day 的任务；未选择时 `data` 为 `null`。 |

## 当前路线字段

`CurrentPlanResponse` 包含：

- `planId`、`planCode`、`planName`
- `durationDays`
- `startedAt`
- `timeProgressDay`

`timeProgressDay` 通过路线开始日期计算，最大值不超过路线总天数。它不等于学习完成度；B03 将以 `study_progress` 另行计算知识完成状态。

## 错误语义

- 不存在或已停用的路线：HTTP 404，`RESOURCE_NOT_FOUND`。
- 默认学习档案缺失：HTTP 404，属于数据库初始化异常。
- 当前路线缺少对应 Day：HTTP 409，`BUSINESS_RULE_VIOLATED`，用于暴露系统路线内容不完整。
