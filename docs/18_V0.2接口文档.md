# 18 V0.2 接口文档

本文件记录 V0.2 已提供的学习接口。统一响应沿用 `ApiResponse`。

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/study/plans` | 返回 10 天、15 天、30 天预设路线摘要。 |
| GET | `/api/study/plans/{planId}` | 返回路线的每日计划和关联内容。 |
| POST | `/api/study/plans/{planId}/activate` | 选择路线并开始一轮新的自然时间进度。 |
| GET | `/api/study/current-plan` | 返回当前路线；未选择时 `data` 为 `null`。 |
| GET | `/api/study/today` | 返回当前 Day 的任务；未选择时 `data` 为 `null`。 |
| POST | `/api/study/attempts` | 追加一次答题历史；相同 `clientAttemptId` 只回读原 attempt、当前 progress 与当前 pending review。 |
| GET | `/api/study/questions/{questionId}/progress` | 返回单题当前学习快照；从未学习时返回默认 PREVIEW / UNKNOWN 状态。 |
| GET | `/api/study/wrong-questions` | 当前启用的激活错题摘要。 |
| PUT | `/api/study/questions/{questionId}/wrong-book/resolve` | 手工标记错题已解决。 |
| GET/POST/DELETE | `/api/study/favorites[/questions/{questionId}]` | 收藏列表、收藏和取消收藏。 |
| GET/POST/PUT | `/api/study/notes`、`/api/study/notes/{id}` | 读取、创建和带 version 的笔记保存。 |
| GET | `/api/study/reviews/today` | 今日到期复习任务。 |
| GET | `/api/study/reviews/due` | 逾期加今日到期的待复习任务，响应含 `overdue`。 |
| GET | `/api/study/reviews?status=PENDING` | 指定状态的复习任务。 |
| GET | `/api/dashboard` | 首页学习进度聚合数据，含 `dueReviewCount`。 |

## V0.2.1 响应语义

`POST /api/study/attempts` 始终返回 `attempt`、`progress`、`review` 和 `duplicated`：

- 首次提交：`duplicated=false`，在同一事务中追加历史、更新快照并替换 pending review。
- 相同 `clientAttemptId` 重试：`duplicated=true`，不重复写入，只回读当前 progress 和当前 pending review。

`StudyProgressResponse` 同时提供 `stageDescription` 与 `masteryDescription`。无进度题目返回 `stage=PREVIEW`、`masteryLevel=UNKNOWN`、计数为 `0`、`lastStudiedAt=null`，而非 404。

`ReviewTaskResponse.overdue=true` 表示 `dueAt` 早于当前自然日零点。`/reviews/due` 与 Dashboard 的 `dueReviewCount` 统一使用“逾期加今日”的口径；保留 `todayReviewCount` 和 `/reviews/today` 以兼容既有调用，它们只统计当天。

## 当前路线字段

`CurrentPlanResponse` 包含：

- `planId`、`planCode`、`planName`
- `durationDays`
- `startedAt`
- `timeProgressDay`

`timeProgressDay` 通过路线开始日期计算，最大值不超过路线总天数。它不等于学习完成度；B03 将以 `study_progress` 另行计算知识完成状态。

## 错误语义

- 不存在或已停用的路线：HTTP 404，`RESOURCE_NOT_FOUND`。
- 默认学习档案缺失：HTTP 404，属于数据库初始化异常。
- 当前路线缺少对应 Day：HTTP 409，`BUSINESS_RULE_VIOLATED`，用于暴露系统路线内容不完整。
- 题目不存在或已停用：HTTP 404，`RESOURCE_NOT_FOUND`。
- `selfRating` 不在 1～5，或 `elapsedMs` 为负：HTTP 400，`VALIDATION_FAILED`。
- 笔记 version 不是当前版本：HTTP 409，`VERSION_CONFLICT`，服务端不会覆盖已保存内容。
- `SCENARIO` 笔记目标尚未在 V0.2 开放：HTTP 409，`BUSINESS_RULE_VIOLATED`。

## 前端客户端约定

- `ApiRequestError` 统一保存 `code`、`status`、`traceId`。页面按 `code` 判断业务异常，不能解析中文 `message`。
- 网络不可达统一抛出 `NETWORK_ERROR`；非 JSON HTTP 响应返回 `HTTP_ERROR` 和 HTTP 状态码。
- `POST /api/study/attempts` 的 `clientAttemptId` 在用户点击“开始练习”时生成。失败重试必须复用该 UUID；只有服务端成功响应后点击“再练一次”才生成新的 UUID。
- 题目提交成功后失效单题 progress、Dashboard、due review 和错题本 queryKey，页面始终以服务端快照为准。
