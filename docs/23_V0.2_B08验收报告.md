## 可靠性覆盖

- 同一 `clientAttemptId` 重试只返回原 attempt，不重复推进 progress 或 review。
- progress 写入失败时 attempt 回滚。
- review 写入失败时 attempt 与 progress 一并回滚。
- 错题解决后从列表消失，再次 WRONG 会重新出现。
- 收藏重复请求幂等，取消收藏可安全重复。
- 笔记旧 version 返回 409，不能覆盖新版本内容。
- 同题新提交完成旧 pending review，并只留下一个 pending。
