# 24 V0.2.1 后端优化验收报告

日期：2026-08-20。

## 完成范围

- 待处理复习改为逾期与当日的合并语义。昨天仍为 `PENDING` 的任务会继续出现在 `/api/study/reviews/due` 和 Dashboard 的 `dueReviewCount` 中；明日任务不会提前出现。
- 重复 `clientAttemptId` 只回读原答题历史、当前学习快照和当前 pending review，响应 `duplicated=true`，不重复推进 attempt、progress 或 review。
- 新增单题学习进度读取。无学习记录时返回 `PREVIEW`、`UNKNOWN`、零计数和空 `lastStudiedAt`。
- 笔记首次创建使用 PostgreSQL 唯一键与 `ON CONFLICT DO NOTHING` 处理竞争；后到请求回读先到请求的内容，后续编辑仍由 version 乐观锁保护。
- 提交编排服务在内部使用 Entity 传递进度和复习任务；Mapper 保持 XML SQL，档案行锁仍覆盖首次 progress 创建竞争。
